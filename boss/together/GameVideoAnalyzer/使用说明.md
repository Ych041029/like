# 游戏视频分析工具 使用说明

> 通过一段游戏游玩视频，自动分析并输出：游戏概述、核心循环（含环形流程图）、核心机制、UI 元素、游玩节奏时间轴。
> 内置 15 种主流游戏类型识别（RPG / 射击 / MOBA / 生存建造 / 卡牌 / 经营 / 格斗 / 赛车 / 音游 / 解谜 等）。

---

## 一、环境准备（只需做一次）

### 1. 安装 Python（3.8 及以上）

- 下载：https://www.python.org/downloads/
- 安装时 **务必勾选「Add Python to PATH」**（重要！）
- 验证：打开 CMD，输入 `python --version`，能看到版本号即可

### 2. 安装 ffmpeg

- 下载：https://www.gyan.dev/ffmpeg/builds/  → 选 `ffmpeg-release-essentials.zip`
- 解压后把 `bin` 文件夹路径（如 `C:\ffmpeg\bin`）加到系统环境变量 PATH
- 验证：CMD 输入 `ffmpeg -version`，能看到版本信息即可

### 3. 安装 Python 依赖（打开 CMD 执行）

```bat
pip install paddleocr paddlepaddle opencv-python numpy pillow matplotlib
```

> 安装较慢时可加国内镜像源：
> ```bat
> pip install paddleocr paddlepaddle opencv-python numpy pillow matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

验证安装成功：
```bat
python -c "import paddleocr, cv2, numpy, PIL, matplotlib; print('依赖全部就绪')"
```
输出 `依赖全部就绪` 即可。

## 二、基本用法

打开 CMD（Win+R 输入 cmd），输入下面命令：

### 1. 最简单用法

```bat
python "脚本路径\game_analyzer.py" "视频路径.mp4"
```

**例**（脚本放在 D 盘，视频在桌面）：
```bat
python "D:\GameVideoAnalyzer\game_analyzer.py" "C:\Users\你的用户名\Desktop\新游戏.mp4"
```

### 2. 指定输出目录（推荐，方便管理）

```bat
python "D:\GameVideoAnalyzer\game_analyzer.py" "D:\新游戏.mp4" --out "D:\报告\新游戏"
```
目录不存在会自动创建。

### 3. 完整参数说明

```bat
python game_analyzer.py [视频路径] [采样帧数] [--out 输出目录]
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 视频路径 | 游戏视频文件 | 脚本顶部 VIDEO 变量 |
| 采样帧数 | 用于分析的帧数（越大越准越慢） | 90 |
| --out 目录 | 输出目录 | D:\ych\no.1（可改脚本顶部 OUT_DIR） |

## 三、运行过程

回车后脚本自动跑 6 个阶段，约 4-7 分钟（30 分钟视频为例）：

```
[1/6] 探测视频          ← 读视频时长/分辨率
[2/6] 抽帧（一秒两帧）   ← 约2-4分钟，抽照片
[3/6] 采样代表帧         ← 选90张分析
[4/6] OCR 文字提取       ← 约2分钟，识别画面文字
[5/6] 分析概述与循环     ← 几秒
[6/6] 组装报告 + 画图    ← 几秒

✅ done -> 输出目录\game_report_时间戳.md
```

**看到 `✅ done` 就是成功了。**

---

## 四、查看结果

运行完成后，去输出目录，会生成：

| 文件 | 说明 |
|------|------|
| **game_report_时间戳.md** | ⭐ 分析报告（重点看这个），用 Typora / VSCode / 记事本打开 |
| core_loop_时间戳.png | 核心循环环形流程图（报告里已引用） |
| frames\ | 抽出的所有照片 |
| report\ocr_results.json | 完整 OCR 文字数据 |

> ⚠️ 报告 `.md` 和环形图 `.png` 要放**同一文件夹**，图才能正常显示。

报告包含 7 个部分：
1. 游戏概述（类型、视角、总体玩法）
2. 核心循环（环形图 + 文字步骤链）
3. 核心机制（战斗/养成/经济等）
4. 画面与 UI 元素
5. 游玩节奏时间轴
6. 高频动作词统计
7. 分析说明（数据来源与局限）

## 五、可选：接入视觉大模型（分析更准）

本地分析靠 OCR 文字识别，对**文字多的游戏**（RPG、经营）很准。
如果是**文字少**的游戏（射击、音游、动作），建议接入视觉大模型增强：

```bat
set GAME_LLM_API_KEY=sk-你的key
set GAME_LLM_BASE_URL=https://api.openai.com/v1
set GAME_LLM_MODEL=gpt-4o
python game_analyzer.py "视频.mp4" --out "输出目录"
```

> 注意：`set` 只在当前 CMD 窗口有效，关掉窗口要重新设置。
> 支持 OpenAI 兼容的任意端点（如智谱、通义、DeepSeek 等的视觉模型）。

## 六、常见问题

### Q1 提示「视频不存在」
- 检查路径是否正确，**中文/空格路径要用英文双引号包起来**
- 例：`python game_analyzer.py "D:\my videos\game.mp4"`

### Q2 提示「ffprobe 失败」或「ffmpeg 不是内部命令」
- ffmpeg 没装好或没加到 PATH，参考「环境准备」第 2 步

### Q3 运行报错 ModuleNotFoundError
- 依赖没装全，重新执行 `pip install paddleocr paddlepaddle opencv-python numpy pillow matplotlib`

### Q4 分析结果不准 / 类型判断错误
- 文字少的游戏本地分析会偏弱，建议启用视觉大模型（第五节）
- 或增大采样帧数：`python game_analyzer.py 视频.mp4 150`

### Q5 想换默认输出目录
- 用记事本打开 `game_analyzer.py`，找到顶部 `OUT_DIR = r"D:\ych\no.1"`，改成你想要的路径

### Q6 第一次运行很慢 / 在下载模型
- PaddleOCR 首次运行会自动下载识别模型（约几百 MB），下载完后续就快了

