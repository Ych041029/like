# 游戏任务分析工具 - 环境安装说明（给新电脑/新同事）

> 本工具用于分析游戏录像视频,自动输出"主线任务时间线"。
> 第一次在新电脑上使用,需要按本文档安装环境(只需装一次)。

---

## 需要装什么(清单总览)

| 序号 | 名称 | 功能(为什么需要它) | 必须手动装? |
|---|---|---|---|
| 1 | Python 3.10 | 运行脚本的"引擎",没有它脚本跑不了 | ✅ 手动 |
| 2 | ffmpeg + ffprobe | 从视频里"抽帧"(把视频切成一张张图片),没有它没法切视频 | ✅ 手动 |
| 3 | numpy (<2) | 数值计算,把图片转成数字给OCR识别 | 自动装 |
| 4 | paddlepaddle | OCR的"算力引擎",驱动识字 | 自动装 |
| 5 | paddleocr | "识字工人",把图片里的字认出来(核心能力) | 自动装 |
| 6 | Pillow | 图片处理(打开/放大/保存图片) | 自动装 |

**手动装2个(Python、ffmpeg),其余4个会自动装。**

---

## 第一步:安装 Python 3.10

### 为什么需要
整个工具是Python写的。Python是"引擎",没它脚本跑不起来。

### 怎么装
1. 打开 https://www.python.org/downloads/
2. 下载 **Python 3.10**(建议版本,3.8-3.10都行)
3. 双击安装,⚠️ **务必勾选 "Add Python to PATH"**(底部第一个选项)
4. 安装完成后,打开命令行(按Win+R,输入cmd回车),输入:
   ```
   python --version
   ```
   能看到 `Python 3.10.x` 就成功了。

---

## 第二步:安装 ffmpeg + ffprobe

### 为什么需要
工具用ffmpeg从视频里"抽帧"——把视频按"1秒2帧"切成一张张jpg图片,然后OCR才能识别每帧的任务文字。ffprobe用来读视频时长。没有它们,工具没法处理视频。

### 怎么装(Windows)
1. 打开 https://www.gyan.dev/ffmpeg/builds/ (ffmpeg官方推荐下载站)
2. 下载 **ffmpeg-release-essentials.zip**
3. 解压到一个固定位置,比如 `C:\ffmpeg`(解压后里面有bin文件夹,bin里有ffmpeg.exe)
4. 添加到系统PATH:
   - 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
   - 在"系统变量"找 `Path` → 编辑 → 新建 → 输入 `C:\ffmpeg\bin`
   - 一路确定
5. **重启命令行**(关掉cmd重开),输入:
   ```
   ffmpeg -version
   ```
   能看到版本号就成功了。

### 验证
```
ffmpeg -version
ffprobe -version
```
两个都能看到版本号,说明装好了。

---

## 第三步:一键安装Python依赖库

### 为什么需要
工具识别文字要用到 paddleocr(识字工人)、paddlepaddle(OCR引擎)、numpy(数值计算)、Pillow(图片处理)。这4个库,Python本身不带,要额外装。

### 怎么装(最简单)
1. 双击本目录里的 **`一键安装.bat`**
2. 等它自动安装(首次约5-15分钟,会从清华镜像下载)
3. 安装完会自动验证,显示OK就成功

### 或者手动装(命令行)
打开命令行,进入本目录,输入:
```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 验证
```
python -c "import paddleocr; print('paddleocr OK')"
```
显示 `paddleocr OK` 就成功了。

## 常见问题

### Q1: pip install 报错 "Microsoft Visual C++ 14.0 is required"
**A:** 需要装 C++ 构建工具。下载 https://visualstudio.microsoft.com/visual-cpp-build-tools/ ,安装时勾选"使用C++的桌面开发"。

### Q2: paddlepaddle 报错 numpy 不兼容
**A:** numpy必须是1.x版本。执行:
```
pip install "numpy<2"
```
我们已经在requirements.txt里写死 `numpy<2`,正常不会出这问题。

### Q3: ffmpeg 命令找不到
**A:** ffmpeg没加到PATH,或没重启命令行。按第二步重新配置PATH,然后**重启命令行**。

### Q4: 首次运行卡在"正在加载PaddleOCR模型"
**A:** 在下载模型(约100MB),等几分钟。如果太久,可能是网络问题,换个网络环境或用代理。

### Q5: 抽帧时报错 "ffprobe" 或 "ffmpeg" 不是内部命令
**A:** ffmpeg没装好,或没加到PATH。见第二步。
