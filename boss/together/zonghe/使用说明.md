# 整合工具使用说明（任务1 + 任务2 一键跑）

> 📌 **路径约定**：本文所有路径相对 together 文件夹（下称"根"）。
> 使用时把"根"换成你电脑上 together 的实际位置（例：`D:\tools\together`）。

## 最简流程（记住一句话：视频进 videos，报告出 reports）

```
① 把视频丢进 根\videos\          文件名起好认的名字，如 跃动小子2.mp4
② 跑一条命令（或交给AI跑）：
   python "根\zonghe\run_all.py" "跃动小子2" --panel 60,498,140,44 --scale 3
③ 等跑完，去固定位置看结果：
   根\reports\跃动小子2\总报告_跃动小子2.md   ⭐
```

- 视频名可带可不带扩展名（`"跃动小子2"` 或 `"跃动小子2.mp4"` 都行）
- **不用传 --out**，报告自动输出到 `reports\视频名\`，不同视频互不干扰
- 传完整视频路径（不放 videos）的老用法也完全兼容

**带具体路径的示例**（假设工具放在 D:\tools，分析神器传说）：
```bat
python "D:\tools\together\zonghe\run_all.py" "神器传说1" --panel 25,744,185,48 --task-below --scale 3
```

## 它会自动做什么

```
[0]   抽帧一次（2fps 一秒两帧）→ frames/     ← 两个任务共用，只抽一次
[任务1] 游戏概述/核心循环/机制（快，采样90帧OCR，几分钟）
[任务2] 主线任务时间线 + 漏任务核查（慢，全帧OCR，30分钟视频约2-10小时，建议挂着）
[3]   自动汇总 → 总报告_视频名.md（固定输出到 reports\视频名\）
```

**总报告**包含：第一部分 游戏概述与核心循环（含环形图）/ 第二部分 主线任务时间线 / 第三部分 候选漏任务清单 / 附录 产物清单。

## 参数速查

| 参数 | 作用 | 说明 |
|------|------|------|
| 视频名或路径 | 要分析的视频 | `videos\` 里的文件名（可省扩展名）或完整路径 |
| `--panel x,y,w,h` | 任务面板坐标 | **新游戏第一次跑需要先定位**；同款游戏可复用 |
| `--task-below` | 任务名在进度数字**下方** | 神器传说类布局要加 |
| `--scale N` | 任务2 OCR 放大倍数（默认2） | 竖屏小字游戏用 3 |
| `--prog-y y1,y2` | 经验条 y 范围 | 有经验条干扰时排除 |
| `--fps N` | 抽帧率（默认2=一秒两帧） | 一般不改 |
| `--out 目录` | 输出目录 | **默认 reports\视频名\，一般不用传** |
| `--audit-min-count N` | 漏任务候选最低出现次数（默认3） | 清单太吵可调高 |

## 已知游戏参数表

| 游戏 | 参数 |
|------|------|
| 神器传说（竖屏修仙） | `--panel 25,744,185,48 --task-below --scale 3` |
| 跃动小子（竖屏ARPG/试炼塔） | `--panel 60,498,140,44 --scale 3`（任务名在进度**上方**，勿加 --task-below） |

## 新游戏第一次跑

1. 不传 `--panel` 先跑一次（自动定位面板），看时间线是否正常
2. 不正常 → 按 `分析视频工具\新会话AI使用说明.md` 第2步定位面板坐标，带 `--panel` 重跑
3. 跑通后把参数记进上面表格，下次同款直接用

## 目录结构（结构不能拆，位置随便放）

```
together\                        ← 放哪个盘、哪个目录都可以
├── videos\      ← 视频输入（把要分析的视频丢这里）
├── reports\     ← 报告输出（自动按视频名建子文件夹）
├── GameVideoAnalyzer\game_analyzer.py
├── 分析视频工具\游戏任务分析_含漏任务核查.py
└── zonghe\
    ├── run_all.py        ← ★ 入口
    ├── 一键安装.bat
    └── 使用说明.md / 新会话AI使用说明.md
```

> 三个脚本按相对位置互相引用，整个 together 一起拷贝/移动才能用；内部结构勿拆散。

## 注意

- 任务2全帧 OCR 很耗时（30分钟视频约2-10小时），建议挂后台或睡前跑
- Windows 控制台中文可能乱码：先 `chcp 65001`；**看结果打开 .md 文件**
- 转发整套工具给别人：整个 together 文件夹打包 zip（videos/reports 里的个人文件可先清空）
