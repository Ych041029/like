# boss 游戏分析总工具 — 使用说明（人用版）

> 📌 路径约定：本文所有路径相对 boss 文件夹。使用时把"根"换成你电脑上 boss 的实际位置。

## 这套总工具能干什么

| 想知道 | 用哪路 | 产出 |
|--------|--------|------|
| 这游戏怎么玩（概述/核心循环/机制） | together | 游戏概述报告 + 核心循环环形图 |
| 这段视频里做了什么任务（明细到秒） | together | 主线任务时间线表 + 漏任务清单 |
| 游戏功能什么时间解锁（图标变亮时刻） | unlock_tool | 解锁时间线 + 证据截图 + 审计 |
| **全都要** | 两路都跑 | ⭐ **一份《游戏分析总报告》打包以上全部** |

## 最简流程（推荐交给 AI）

```
① 视频丢进 根\videos\（boss自己的videos文件夹，两路工具共用同一个视频）
② 开AI会话说：
   请阅读 "根\新会话AI总手册.md"，工具根目录是 根 的实际路径，
   分析 videos 里的 视频名，玩法和解锁时间线都要，
   最后合并成总报告。
③ AI 调度两路工具（解锁那路需要你配合拖框标定/核验证据），
   完成后去固定位置看结果：
   根\reports\视频名\游戏分析总报告_视频名.md   ⭐
```

## 目录结构（结构不能拆，位置随便放）

```
boss\
├── videos\          ★ 视频统一丢这里（两路工具共用）
├── together\        工具1：玩法/任务分析（中间报告出在 together\reports\）
├── unlock_tool\     工具2：解锁时间线（games存标定和证据→reports发布）
├── merge_report.py  总汇总脚本（两路结果→一份大报告）
├── 新会话AI总手册.md AI调度入口（给AI读）
├── 总说明.md        本文档
└── reports\         ⭐ 最终交付物（游戏分析总报告）
```

## 环境准备（一次性）

装 Python 3.10 + ffmpeg + 依赖库——交给 AI 全自动装：
跟 AI 说「读 根\together\zonghe\环境自动安装(AI执行).md 帮我装环境」，
并提醒它 **opencv 必须是 4.6.0.66 正式版**（两边工具的共用锁定版本）。
也可手动：Python3.10 → ffmpeg → 双击 together\zonghe\一键安装.bat →
再执行 `pip install opencv-python==4.6.0.66`。

## 手动合并报告（AI没代跑时自己拼）

```
python "根\merge_report.py" 视频名
```
（视频名和游戏名不同时：`--video-name X --game-name Y`）

## 注意

- 工具2每款新游戏需要一次"拖框标定"（人来做，1-2分钟）；之后同款游戏全自动
- 30分钟视频：工具1约2-10小时，工具2视 fps 设置更久，建议挂后台/睡前跑
- 转发别人：整个 boss 打包；two videos/reports/games 里个人数据可先清空
